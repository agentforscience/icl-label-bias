\section{Experimental Details}
\label{app:details}

\para{Data sources.} \sst and \agnews were loaded from the local Hugging Face cache. \rte and \mrpc were loaded from the \texttt{nyu-mll/glue} parquet files. Test sets are gold-balanced: 100/100 for binary tasks and 50 per class for \agnews.

\para{Example prompt (\sst).}
\begin{lstlisting}
Classify the sentiment of each movie review as positive or negative.

Review: <demo text>
Sentiment: positive

... (10 demonstrations) ...
Review: <test text>
Sentiment:
\end{lstlisting}

\para{Scoring.} We use vLLM 0.32 with \texttt{allowed\_token\_ids} set to the first token of each label word (with a leading space) and \texttt{logprobs\_mode="processed\_logprobs"}, so the returned log-probabilities are renormalised over the label set. Decoding is greedy with seed 0.

\para{Seeds.} Demonstration sampling is seeded by an MD5 hash of (task, item, $T$, condition). The analysis RNG seed is 0.

\para{Compute.} Each run used one slice of a shared NVIDIA RTX A6000 (48\,GB), with 5--44\,GB available depending on other users' jobs. The 14B run took 74 minutes; the 0.5B--1.5B runs took 2--4 minutes each. The total was about 6 GPU-hours, with no API cost.

\para{Software.} vLLM 0.32.0, PyTorch 2.13, Transformers 5.19, pandas 3.0, matplotlib, Python 3.12.
